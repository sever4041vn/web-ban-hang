# Cách sử dụng/VI

## 1. Cài xampp
  Tải xampp tại: https://www.apachefriends.org/download.html
  Cài đặt như bình thường
  Khởi động website bằng cách mở xampp và bật Apache, MySql
  Nếu muốn nó khởi động khi bật máy tính thì hãy tải service ở kế bên

## 2. Thiết lập database
  Truy cập phpmyadmin: http://localhost/phpmyadmin
  Vào phần sql và thực thi lệnh trong phần database.txt
  Trong file /config/db.php
  Thay đổi phần username và password nếu bạn đã thêm mật khẩu cho mysql

## 3. Sử dụng bình thường

>*Web này chỉ được dùng trong máy chủ nội bộ làm ra chỉ để cho vui*  

# How to use/ EN

## 1. Install xampp
  Install xampp at this link: https://www.apachefriends.org/download.html
  Install normally
  Starting website by opening xampp app and turning on apache, mysql
  If you want to start when opening computer, you should install service by the next button

## 2. Adjust database
  Access phpmyadmin: http://localhost/phpmyadmin
  Going to sql section and execute the command on database.txt
  In file /config/db.php
  If you change password for mysql, you should change username and password

## 3. Using this normally

>*This website only use for local server and this create just for fun*
